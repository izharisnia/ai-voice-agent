    Step 01

    API Key Setup & Configuration

    Click API Keys in top header navigation. Input your Gemini API key (Free key available at Google AI Studio).

    STT, TTS, Weather & News run 100% free without paid keys.
    Step 02

    Select Audio Streaming Mode

    In Voice Studio, locate the Real-Time Stream toggle:

    • ON (Recommended): Streams audio chunks in real-time over WebSockets for minimal latency.
    • OFF: Standard HTTP mode where recorded audio is sent upon recording finish.
    Step 03

    Record Your Voice Prompt

    Tap the central Glowing Mic Button or Voice Orb to start listening.

    • Orb pulses in bright magenta/pink while capturing audio.
    • Speak clearly (e.g. "What is the weather in London?").
    • Tap mic button again to finalize turn.
    Step 04

    Native Gemini Tool Execution

    Gemini LLM uses Native Function Calling to execute live tools autonomously:

    • Ask "Weather in Paris" to run live weather API.
    • Ask "Top breaking news" to query Google News RSS.
    Step 05

    SQLite Thread Persistence

    All turns are saved in local SQLite DB (`voice_agent.db`). Click + New Chat in sidebar to start a new thread or load history.
